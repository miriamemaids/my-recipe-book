MY RECIPE BOOK – how to put it online (about 5 minutes, on a computer)

1. Unzip this file. You'll get a folder called my-recipe-book.
2. Go to app.netlify.com and sign in.
   - To keep your old link: open your existing recipe site > Deploys,
     and drag the my-recipe-book folder onto the box that says
     "Need to update your site? Drag and drop your project folder here".
   - For a new link: go to app.netlify.com/drop and drag the folder there.
3. Wait for the deploy to finish (a minute or two), then open the site.
4. Tap "Add recipe" to add one from a photo, pasted text, or by typing.
   Anyone with the link can add and edit recipes.

Adding recipes from photos uses Netlify's built-in AI, which comes
out of the free plan's monthly credits. No API key or card needed.
